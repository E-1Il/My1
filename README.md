# My1

這是一個包含多個Python練習專案的倉庫。

## 專案內容

### 1. 猜數字遊戲 (Gn.py)
- 經典的猜數字遊戲
- 隨機生成1到100之間的數字
- 玩家猜測並得到「大了」或「小了」的提示

### 2. 分數計算器 (Sc.py)
- 簡單的成績平均分數計算器
- 支援多個成績輸入
- 包含錯誤處理功能

### 3. 安全除法 (safe_division.py)
- 提供安全的除法運算
- 自動處理除數為零的情況
- 包含完整的單元測試

### 4. 五子棋遊戲 (Gomoku.py)
- 完整的雙人五子棋對戰遊戲
- 15x15棋盤，支援兩位玩家輪流對弈
- 包含詳細的遊戲規則和策略說明
- 自動判定勝負和平局

## 五子棋遊戲說明

五子棋（Gomoku）是一種源自中國的策略棋盤遊戲，也稱為「連五子」或「五子連珠」。

**遊戲規則：**
- 使用15x15的棋盤
- 兩位玩家分別使用黑子(●)和白子(○)
- 黑方先行
- 玩家輪流在空位放置棋子
- 先在橫向、縱向或斜向連成五個同色棋子者獲勝

**策略要點：**
- 進攻：建立活三、活四等優勢局面
- 防守：阻擋對手的連珠
- 雙重威脅：同時建立多條進攻路線

**執行方式：**
```bash
python Gomoku.py
```

## 如何使用

每個Python檔案都可以直接執行：
```bash
python Gn.py        # 猜數字遊戲
python Sc.py        # 分數計算器
python safe_division.py  # 安全除法示例
python Gomoku.py    # 五子棋遊戲
```
